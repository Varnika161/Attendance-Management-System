# Attendance Management System

## About the Project
The Attendance Management System is a web-based application developed using Java and Spring Boot. It helps manage student attendance and makes attendance tracking easier and more organized.

## Features
- Student management
- Attendance recording
- Attendance percentage calculation
- Subject-wise attendance management
- View attendance records
- REST API integration

## Technologies Used
- Java
- Spring Boot
- Maven
- SQL
- HTML
- CSS
- JavaScript

## Project Structure
- Controller: Handles incoming requests.
- Model: Contains application data classes.
- Repository: Handles database operations.
- Service: Contains business logic.
- Resources: Contains SQL scripts, configuration and frontend files.

## How to Run the Project

1. Install Java JDK.
2. Install or configure Maven.
3. Clone this repository.
4. Open the project in IntelliJ IDEA, Eclipse or VS Code.
5. Configure the database if required.
6. Run the AttendanceApplication.java file.
7. Open the application in your browser using the configured local server address.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Attendance-Management-System.git
```

Navigate to the project directory and run:

```bash
mvn spring-boot:run
```
